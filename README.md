# 계약 단계 체크 대시보드

프로젝트별 **매출(영업) 계약 단계** 진행 현황을 한 화면에서 체크하기 위한 내부용 도구입니다.
구글 시트를 실시간으로 읽어 단계별 체크(O / X / -)와 진행율만 보여줍니다.

> 매입(purchase) 단계는 동일 구조로 나중에 확장합니다. (현재는 매출만)

## 동작 방식

- 데이터는 **브라우저에서 직접** 구글 시트를 읽습니다(별도 서버 없음).
- 화면에는 단계 체크와 진행율만 표시합니다. **금액·고객사 등 대외비 값은
  렌더링하지 않으며, 어떤 데이터도 저장소에 커밋하지 않습니다.**

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

빌드/미리보기:

```bash
npm run build
npm run preview
```

## 시트 연결

- 시트 ID / gid 는 `src/config.js` 의 `SHEET_ID`, `GID` 에 있습니다.
- URL 파라미터로도 덮어쓸 수 있습니다: `?sheetId=<ID>&gid=<GID>`
- **시트 공유 설정**이 "링크가 있는 모든 사용자 - 뷰어" 이상이어야 브라우저에서
  읽을 수 있습니다. 비공개면 권한/CORS 오류가 납니다.

## 매출금액 회수율 / 계약금 / 계약링크

- **매출 회수율** = `회수액(CB) / (회수액(CB) + 세금계산서 미발행(CC) + 미수채권(CD))`.
  세 값이 모두 0/빈값이면 산정 불가로 `-` 표시.
- **계약금**(AD열, 총 계약금): 대외비 금액이라 기본적으로 **표시하지 않는다.**
  인증이 걸린 호스팅에서만 보이도록 빌드 시 환경변수로 켠다:

  ```bash
  VITE_SHOW_AMOUNTS=true npm run build
  ```

  공개 GitHub Pages 빌드에는 이 변수가 없으므로 계약금 컬럼이 나오지 않는다.
  (시트 원본 CSV에는 금액이 포함되어 브라우저로 전송되는 점은 동일하므로,
   민감 데이터는 인증 호스팅으로 옮기는 것을 권장)
- **계약링크**: 계약기안 셀의 표시텍스트(예: `link`, `원계약`)를 그대로 보여준다.
  시트의 링크 셀은 실제 URL이 아니라 표시텍스트만 있어 클릭 가능한 링크는 만들 수 없다.

## 단계 매핑 (조정 포인트)

`src/config.js` 의 `GROUPS` 에서 그룹/단계와 시트 컬럼 매핑을 정의합니다.

- `match`: 시트 헤더명 후보(부분일치). 헤더명이 바뀌어도 후보를 추가하면 됩니다.
- `rule`:
  - `fill` — 값이 채워져 있으면 완료(날짜/링크 계열)
  - `token` — 값의 토큰을 해석(상태 계열)

판정 토큰(완료/미완료/해당없음)은 `src/derive.js` 상단에서 조정합니다.

### ⚠ 확인 필요

실제 시트 셀 값을 직접 확인하지 못한 상태로 합리적 기본값을 넣었습니다.
다음을 시트 실제 표기에 맞게 점검하세요.

- O/X/- 판정 토큰 (`derive.js` 의 `DONE_TOKENS` / `NO_TOKENS` / `NA_TOKENS`)
- 이미지의 계약 **"발송"** 단계는 현재 시트 스키마에서 대응 컬럼을 특정하지
  못해 제외했습니다. 해당 컬럼이 있으면 `config.js` 에 추가하세요.

## 구조

```
src/
  config.js       시트 연결 + 단계 매핑 (주요 조정 파일)
  sheet.js        시트 fetch + CSV 파싱 + 컬럼 인덱스 해석
  derive.js       행 → 프로젝트 모델 변환, 단계 상태 판정
  App.jsx         상태/필터 + 레이아웃
  components/
    Summary.jsx   상단 요약 카드
    Filters.jsx   검색/담당자/진행상황 필터
    StageTable.jsx 단계 체크 매트릭스 테이블
```
